What this version does

  • Public inventory discovery via adapters (Lithia / Dealer.com / Generic)
  • SQLite snapshots with NEW / PRICE CHANGE / REMOVED detection foundation
  • REST API for dealerships, vehicles, search, and events
  • Ready for Gunicorn + Render deployment

Key API endpoints

  • GET /api/health — health check
  • GET /api/adapters — available source adapters
  • POST /api/discover — scan a public inventory URL
  • GET /api/vehicles — list / search saved vehicles
  • GET /api/vehicles/<id> — vehicle detail + events
  • GET /api/events — recent inventory events
  • GET /api/dealerships — registered dealerships
